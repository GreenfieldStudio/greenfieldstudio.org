Privacy

Short version: this website doesn't track you. It counts visits, without cookies. The game keeps your progress, and sends crash reports so bugs can be fixed.

This website

  • No cookies, no advertising, no tracking pixels.
  • Visits are counted with Cloudflare Web Analytics, on every page here and each time the game at /play/ is opened. Cloudflare states that it uses no cookies or local storage and doesn't fingerprint visitors. What it reports: which page was viewed, the site you came from, your country, browser, operating system and device type, and how fast the page loaded. See Cloudflare's privacy policy.
  • That counter is the only third party a page loads by itself (static.cloudflareinsights.com and cloudflareinsights.com). Fonts, images, video and film thumbnails are all served from this domain.
  • Greenfield Ambience films play in YouTube's privacy-enhanced player (youtube-nocookie.com), and only after you press play on one. From that moment YouTube serves the film and Google's privacy policy applies to the player. Until you press play, nothing is requested from YouTube.
  • The site is hosted on GitHub Pages. Like any web host, GitHub may log technical data such as IP addresses to keep the service secure. See GitHub's privacy statement.

Minigolf Pro

When you play Minigolf Pro here, the game saves your progress in your browser. Cloud save, leaderboards, community holes and online play use Google Firebase with an anonymous account that is created for you. Error and crash reports are always sent, with any free text scrubbed of email addresses, web addresses and file paths. Gameplay analytics are off unless you switch them on in Settings. YouTube API Services (the studio's own upload tool)

Greenfield Studio uses YouTube API Services in a small internal tool. The tool is run by the studio owner, on the studio's own computer, to schedule and upload the studio's own videos to the studio's own YouTube channels (Greenfield Ambience and Greenfield Studio). It is not a public app or service: nobody else signs in to it, and it has no users apart from the studio.

  • What it can reach. After the owner signs in with Google, the tool can upload and schedule videos on the channel the owner chose, and read that channel's own statistics (views, watch time, subscribers) and the comments on the studio's own videos. The comment text and the public display name of the person who wrote it are read so that the studio can answer questions; display names are stored only as a short scrambled code.
  • What it keeps. The Google sign-in token is stored in a locked folder on the studio computer. Statistics and comments are kept on that computer only, and each daily read replaces the previous one (the statistics keep a daily history of numbers, with no personal data in it). Nothing is sold, shared with a third party, used for advertising or published.
  • Google and YouTube. By using the tool the studio is bound by the YouTube Terms of Service, and Google's handling of your data is described in the Google Privacy Policy. Use of information received from Google APIs follows the YouTube API Services Terms of Service and the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access. The channel owner can withdraw the tool's access at any time in the Google security settings. When access is withdrawn, the studio deletes the stored token and any data it holds from the API within 7 days.
  • Your comments. If you wrote a comment on one of our videos and want it removed from the studio's copy, write to the address below and it is deleted within 7 days. To remove the comment itself, delete it on YouTube.

Terms of use of the tool

The tool is for internal use by Greenfield Studio only. It is not offered to anyone else, has no accounts and costs nothing to anyone. It is provided as it is, without warranty. The studio uses it only in line with the YouTube Terms of Service, the YouTube API Services Terms of Service and the YouTube Developer Policies, and uploads only content the studio made itself. These terms can change; the date at the top of this page shows the last change.
